Getting Started

快速开始

三步启动你的第一个研究项目。

安装

克隆仓库，运行安装脚本，自动检测并安装所有依赖。

Terminal
git clone <repo> ideaseek && cd ideaseek
node scripts/install.mjs
ideaseek doctor

创建项目

新建一个研究方向文件夹，初始化 IdeaSeek 项目。

Terminal
mkdir my-research && cd my-research
ideaseek init
ideaseek setup

放入材料并启动

把论文放进 papers/，数据放进 datasets/，然后一条命令启动。

Terminal
ideaseek start --question "你的研究问题"
就是这么简单。 IdeaSeek 会自动扫描材料、检查环境、创建研究计划，然后告诉你下一步。
Concepts

核心概念

理解这几个概念，就能用好 IdeaSeek。

📁

项目目录

当前目录就是项目。papers/ 放论文，datasets/ 放数据，ideas/ 存放平台生成的实验代码，reports/ 存放报告。

🔄

三种模式

Research（默认）运行实验和分析；Analysis 只读准备和评估；Coding 专注代码修改。用 Shift+Tab 切换。

📊

数据规模

smoke 秒级验证 → quick 分钟级实验 → standard 完整实验。全量训练由你拿到 handoff 后自行执行。

🔒

审批与安全

高影响操作需要确认。API key 只存在 DSH credential store 中，从不写入文件、日志或事件。

🧬

证据链

每个结论都可追溯到输入哈希、版本号和运行 ID。原始论文和数据永远只读，修改只发生在工作副本中。

🤖

多 Agent 协作

平台使用多个 Agent 角色（论文分析、实验设计、代码实现、结果审查），每个角色有独立的权限和工具集。

Workflow

研究流程

从材料到论文的完整链路。

放入材料

论文放 papers/，数据放 datasets/，对比方法放 comparisons/。不确定的放 incoming/。

Terminal
ideaseek scan          # 发现材料
ideaseek intake        # 查看待确认项
ideaseek prepare       # 运行分析准备管线

生成 Idea 并验证

平台从论文和数据中提取证据，生成候选 idea，然后在小规模实验中快速验证。

Terminal
ideaseek idea generate
ideaseek idea implement <id>
ideaseek idea check <id>
ideaseek idea experiment <id>

分析与交付

分析实验结果，生成判定，交付复现包和论文。

Terminal
ideaseek idea analyze <id>
ideaseek idea handoff <id>
ideaseek paper plan
ideaseek paper write
ideaseek paper compile
Interactive

交互与 TUI

启动交互式界面，用自然语言或命令与平台对话。

Terminal
ideaseek interactive
自然语言：直接输入问题，平台从状态中回答。高影响请求会变成待审批的 Decision。
斜杠命令：输入 / 打开命令面板，支持模糊匹配和 Tab 补全。
快捷键：Shift+Tab 切换模式 · Ctrl+F 搜索 · ? 查看快捷键
Reference

CLI 命令

所有命令在当前目录寻找 .research/，大多数支持 --json。

开始与配置

ideaseek init初始化项目目录和配置
ideaseek start --question "..."一键启动：init + setup + 扫描
ideaseek setup自动检测环境并持久化配置
ideaseek doctor检查配置、项目状态和主机环境
ideaseek mode [research|analysis]显示/切换研究档位
ideaseek models setup配置 API key（隐藏输入）
ideaseek interactive启动交互式 TUI 界面
ideaseek projects列出已注册的项目

读懂材料

ideaseek scan发现 papers/code/data 目录下的文件
ideaseek ingest解析所有新 PDF 并索引
ideaseek extract批量提取解析后的论文
ideaseek synthesize聚类 PaperCard、构建研究地图
ideaseek prepare运行 Analysis 只读准备管线
ideaseek assessment研究材料缺口报告

Idea 与实验

ideaseek idea generate生成候选 IdeaCard
ideaseek idea implement <id>用 DSH agent 实现 idea 代码
ideaseek idea check <id>运行检查阶梯
ideaseek idea experiment <id>运行有界实验并记录结果
ideaseek idea analyze <id>分析实验结果，产生判定
ideaseek idea handoff <id>生成全量实验复现包
ideaseek idea run-ready并行运行所有 SMOKE_TESTED 的 idea

论文交付

ideaseek paper plan从结果生成论文大纲
ideaseek paper write起草绑定到计划的稿件
ideaseek paper compile组装并编译为 PDF
ideaseek paper results导出实验结果（确定性）
ideaseek paper diagram渲染 FigureSpec 为 SVG
ideaseek paper export-overleaf打包为 Overleaf ZIP

运行与监控

ideaseek run --question "..."创建或恢复工作流
ideaseek status显示运行状态和任务进度
ideaseek next状态感知的下一步建议
ideaseek attach --run <id>回放并实时跟随事件
ideaseek pause / resume暂停/恢复运行
ideaseek monitor快照心跳、日志和资源

TUI 快捷命令

在交互式界面中输入 / 打开命令面板。

/help显示帮助
/status运行状态、任务、事件
/next下一步建议
/pending等待你的审批
/approve [n]批准待处理项
/papers论文索引进度
/ideasidea 列表
/experiments实验记录和结果
/mode [research|analysis]切换研究档位
/agent <指令>运行 DSH 编码会话
/pause / /resume暂停/恢复运行
/quit退出（不取消后台运行）

快捷键

Shift+Tab切换 Research / Analysis / Coding
Ctrl+F在转录中搜索
Ctrl+Y复制最近一条回复
Ctrl+L清屏定位
Ctrl+R反向历史搜索
?快捷键速查
Troubleshooting

恢复与排错

常见问题和恢复方法。

额度耗尽

运行 ideaseek doctor 检查凭据，充值后 ideaseek continue 从 checkpoint 继续。

网络故障

平台自动暂停在可恢复状态。网络恢复后 ideaseek continue 接着跑，不重复已完成的任务。

进程崩溃

重新打开项目时自动恢复：过期租约回收、中断的提交恢复或重新入队。

API key 配置

运行 ideaseek models setup（隐藏输入），或在 TUI 中输入 /models setup。

注意：原始论文、数据和上游 comparison 仓库永远只读。自动修改只发生在工作副本或 idea 专属目录中。
