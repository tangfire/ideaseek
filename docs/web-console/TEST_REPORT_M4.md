### 1.4 移动适配（F15.1-F15.3）

**文件**：`web/console/src/tokens.css`

- **F15.1 响应式布局**：360px 起
  - `@media (max-width: 768px)` 断点
  - `main` padding 缩小：`20px 16px 64px` → `12px 8px 48px`
  - Hero 区域 padding 和字号缩小

- **F15.2 流水线横向滚动**：
  - `.pipeline` 设置 `overflow-x: auto` + `flex-wrap: nowrap`
  - `-webkit-overflow-scrolling: touch` 平滑滚动
  - `li` 设置 `flex-shrink: 0` 防止压缩

- **F15.3 关键状态首屏可见**：
  - `@media (max-width: 360px)` 断点
  - `status-chip` 字号缩小：12px → 11px
  - `h1`/`h2` 字号缩小
  - `.panel` padding 缩小

- **F15.5 表格降级为卡片**：
  - `table` 改为 `display: block`
  - `thead` 隐藏
  - `tr` 改为卡片样式（背景、边框、圆角、padding）
  - `td` 改为块级元素，第一个 `td` 加粗作为标题
