## 仍需解决的问题

以下两项为仍未接通的已知能力缺口。

### P1：真实实验和结果写入仍未接通

云端 `run_experiment` 执行器仍创建 `simulated` 节点（`web/functions/engine/task-executors.ts:447`）。前端可以用已存在的结构化结果显示指标，但本轮浏览器中的真实结果形状来自测试数据。不能据“实验区显示完整”宣称已经运行了真实实验。

建议下一步先接通一个最小真实实验，保存相互绑定的规格、代码版本、数据快照、协议、随机种子和对照，再用失败/恢复测试验收；保留模拟标签与指标保护。

### P1：用户无法在材料入口补交文件或获取交付物

材料中心明确是只读记录。`web/console/src/resources.tsx:158` 已说明论文上传、数据集接入与代码包/报告下载尚未接通。缺少论文时可以解释阻塞，但用户无法通过此入口解除材料缺口；文件引用也不能变成可下载文件。

建议先完成论文文本或文件的一条最小提交路径，包括权限、大小/类型约束、保存回执及分析任务绑定；下载另需验证真实文件存在、访问权限与链接有效期。
