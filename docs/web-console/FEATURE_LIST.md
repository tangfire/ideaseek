# IdeaSeek Web 控制台 — 完整功能清单

配套：[REQUIREMENTS.md](REQUIREMENTS.md) · [DIAGRAMS.md](DIAGRAMS.md) · [PLAN.md](PLAN.md)

优先级定义：

- **P0** = 没有就不能上线第一版（最小可公开闭环）
- **P1** = 上线后第一批增强，构成产品价值主体
- **P2** = 有余力再做，或依赖引擎侧先具备能力

状态列在开发阶段回填。逐模块复核后总计 **106 项**（P0 45 / P1 41 / P2 20）。

## M1 同步与投影管线（P0，14 项）

本地引擎 → 云端投影的唯一通道，也是**安全边界的实际所在**。

| ID | 功能 | 说明 | 优先级 | 验收标准 |
| --- | --- | --- | :-: | --- |
| F1.1 | `ideaseek cloud link` | 输入控制台地址 + token，验证连通并写入用户级配置 | P0 | 错 token 得到明确失败；token 引用不落明文 |
| F1.2 | `ideaseek cloud push` | 从 SQLite 生成投影并批量上报 | P0 | 首次 push 后网页可见项目 |
| F1.3 | `--dry-run` 投影预览 | 打印将上报的实体计数与字段样例，不发送 | P0 | 与真实 push 的 diff 为空 |
| F1.4 | **L0 脱敏序列化** | secret 形状扫描（`sk-`、PEM、JWT、AKIA、`Bearer`）、绝对路径剥离、论文正文与 prompt 白名单排除 | P0 | 20 种 secret fixture 注入后 0 泄漏；单测常开 |
| F1.5 | 投影 schema 契约 | `cloud-projection-v1.json`，沿用既有 40+ schema 的版本化惯例 | P0 | Function 侧 ajv 校验通过 |
| F1.6 | 版本协商 | Function 拒绝未知主版本，回执原因与建议动作 | P0 | 提交 v99 得到 409 而非静默丢弃 |
| F1.7 | 未知字段拒绝 | 不静默忽略契约外字段 | P0 | 注入未知字段整批 rejected |
| F1.8 | 幂等批 | `external_batch_id` 为唯一键，重放不产生重复行 | P0 | 同一批次 push ×3 后行数不变 |
| F1.9 | 事件游标增量 | 只上报 `seq > last_ack_seq`，`(run_id, seq)` 唯一 | P0 | 断点续传不丢不重 |
| F1.10 | 离线缓冲与重试 | 云端不可达时本地排队，退避重试，不阻塞 run | P0 | 断网 30 min 后恢复，数据最终一致 |
| F1.11 | `cloud status` | 显示最后同步时间、待推数量、上次错误 | P0 | 三态均可读 |
| F1.12 | `cloud disable` | 停止同步并可选立即删除云端投影 | P1 | 关闭后网页读不到新数据 |
| F1.13 | **push 前密钥闸门** | 投影序列化后、出网前做 secret 形状扫描；命中即**整批拒绝**，不存在"警告后继续" | P0 | 注入真 key 形状 fixture，断言零出网（NFR-15） |
| F1.14 | **禁目录遍历** | 投影器只读 SQLite 与 artifact 记录；文件类字段仅取已入库 hash + 相对引用 | P0 | 断言投影全过程不产生 readdir（NFR-14 / R9，`.env` 明文 key 已在 `PROGRESS.md:485` 证实存在） |

## M17 实时推送通道（P0，6 项）

对应需求 §5.4、决议 Q11、非功能 NFR-16。**前置条件是 spike S6**（`PLAN.md §3`）：Function 是否支持 WebSocket 长连接属未验证的平台能力假设，S6 不通则 F17.1–F17.6 整体按 S6 降级方案改传输层，帧语义与验收用例不变。

| ID | 功能 | 说明 | 优先级 | 验收标准 |
| --- | --- | --- | :-: | --- |
| F17.1 | `WS /functions/v1/app/live` 频道 | 按项目订阅；握手时按可见性一次性鉴权 | P0 | WS-05/07/08 鉴权矩阵 |
| F17.2 | 三类帧 | `state`（立即推）/ `events`（批增量 ≤ 50 条或 ≤ 8 KB）/ `ping`（30 s 空闲） | P0 | WS-01/09/12 |
| F17.3 | 物化变更流 | ingest 事务内写 `live_outbox`，广播 worker 消费；WS 层不重新查询投影表 | P0 | 断言"每批 push 的投影表读次数与连接数无关" |
| F17.4 | `seq` + `last_ack_seq` | 连接内单调序号；页面显示"已同步至 seq N"，客户端凭跳号检测空洞 | P0 | WS-04/11 |
