# 联网、内网与离线运行

IdeaSeek 必须区分外部资料访问、模型服务访问和本地实验执行。`allow_network: false` 不能被解释成“所有功能都可离线”，也不能让外部访问失败伪装成成功。

## 运行形态

| 形态 | 模型调用 | 论文/数据/代码发现 | 本地分析与实验 |
|---|---|---|---|
| 联网 | 可用经配置和授权的云模型或内网模型 | 可访问允许的学术索引、数据源和 GitHub | 可用 |
| 实验室内网 | 使用内网部署的 DSH provider/model endpoint | 仅允许访问实验室镜像、代理或白名单源 | 可用 |
| 完全离线 | 仅在配置了本地模型/provider 时可推理；云 API 不可用 | 只处理已放入项目或本地缓存的材料 | 可用，但受本机依赖、硬件和输入格式限制 |

启动和 `doctor` 应展示当前连接形态、每个 provider/route 的 text/image modality、外部来源可达性和功能限制。模型图片能力按 DSH 实际 route capability 判定；不得仅根据模型别名或产品名称推断。

## 外部阻塞与恢复

外网不可达、API 不可达、GitHub/学术索引被拒、下载失败、权限不足、数据需申请或许可证未知时：

1. 把任务持久化为 `NETWORK_BLOCKED`、`AUTH_REQUIRED`、`USER_INPUT_REQUIRED` 或相应的 typed blocked 状态，记录来源、时间、对象、错误类别和受影响下游；
2. 生成用户可读的阻塞说明：缺少什么、影响哪些 comparison/claim/实验、是否可用本地输入替代、需要的下一步命令或用户动作；
3. 只暂停依赖该输入的节点；无依赖的论文整理、代码分析、离线实验和文档生成继续运行；
4. required comparison、关键数据或证据被阻塞时，禁止绕过门禁、静默排除或声称研究闭环完成；scope 变更必须由研究者带理由确认并记录 Decision/Event；
5. 网络/凭据恢复后，从 checkpoint 重试未完成的最小任务；成功 artifact 和全量下载不重复处理，来源/内容 hash 变化则创建新快照并仅失效依赖节点。

## 能力边界

- 本地论文、数据集、comparison clone、缓存索引和本地模型齐备时，断网仍可完成对应的解析、检索、代码 smoke、实验、统计和论文装配。
- 云端 DeepSeek 或其他云 provider 需要能访问其 endpoint；无法访问时进入阻塞，不能称作本地推理。
- 新论文/数据集/代码仓库的外部发现与获取在离线时不可用；Dataset Discovery 应标明检索范围仅为本地语料，不输出“已穷尽相关工作”。
- 本地 embedding、PDF/OCR、绘图和 latex 工具需要预先安装/缓存；缺少依赖时报告具体环境阻塞，提供离线安装包/内部镜像路径，不访问未经授权的外网。
- 联网能力按数据分类、域名白名单和阶段审批管理。用户允许下载公开数据不自动代表允许向第三方模型上传原始私有数据。

此文档定义产品行为契约，不代表联网探测、离线模型安装或所有恢复路径已经实现；实现状态以 `docs/PROGRESS.md` 中有测试和提交证据的项目为准。
